
# 🎣 NTE(Neverness to Everness)自動釣りツール

本ツールは `OpenCV` を使用しているため、バックグラウンドでの動作には対応していません。あらかじめご了承ください。

![レクイエム](./docs/Lacrimosa.png)レクイエムに釣りを任せましょう。

[最新版をダウンロード](https://github.com/HeadmasterTan/NTEFishingTool/releases/tag/v1.1.3) | [過去のバージョン](https://github.com/HeadmasterTan/NTEFishingTool/releases)

## 📘 使用方法

* `zip` ファイルを解凍後、`NTEFishingTool.exe` を **管理者として実行** してください。

* 本ツールには「自動釣り」と「釣り停止」の2つのボタンしかありません。また、`F11` キーを押すことで直接「開始/停止」を切り替えることができます。

* 使用前の準備
	1. 現在、`16:9` `16:10` `24:10` `35:10` の4種類のアスペクト比に対応しています。ご自身の環境と一致しているかご確認ください。
		- 例：`1920 ÷ 1080 = 1.777` の場合は `16 ÷ 9 = 1.777` となります。各自でご確認ください。
	2. ゲームの画面設定は「ウィンドウモード」または「ボーダーレス（仮想フルスクリーン）」を推奨します。また、解像度が高すぎない設定を推奨します（ゲームを4K解像度に設定すると、ツールのパフォーマンスが低下する場合があります）。
	3. ゲーム画面が完全にデスクトップ上に表示されていることを確認してください（画面の端などが隠れないようにしてください）。
	4. 必ず以下の画面（釣り開始状態）になってから、本ツールを起動してください。
	![釣り画面](./docs/FishingScene.png)

* 「自動釣り」を開始した後は、「釣り停止」をクリックするまで、PCの操作を行わないでください。ツールの正常な動作に影響を与える可能性があります。

## ✨ 主な機能

1. 自動釣り機能
2. 釣り餌の自動購入（※ただし「万能釣り餌」のみ購入します）
3. 釣った魚の自動売却（バッグが満杯になった時、または釣り餌がなくなった時に発動）
4. 月間パス（月卡）画面の自動スキップ
5. ログアウト画面（タイトル画面）から自動でゲームに再入場
6. 多言語対応
7. ほとんどの画面アスペクト比・解像度に対応

## ❔ Q&A

### Q：カーソルが緑のバーに追いつきません。

- ゲームの画質や解像度を少し下げてみてください。
- カラー強調や画面フィルターなどの機能を設定している場合は、オフにすることをおすすめします。
- 釣りをしている場所の背景が複雑すぎる可能性があります。別の釣りスポットを試してみてください。
- AMD製グラフィックボードをご使用の場合は、フレーム生成（Frame Generation）機能をオフにしてみてください。
- 上記を試しても解決しない場合、現時点では対応策がありません。
