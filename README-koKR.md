
# 🎣 이환 (Neverness to Everness) 자동 낚시 툴

본 툴은 `OpenCV` 기반으로 제작되어 백그라운드 실행을 지원하지 않으니 이용에 참고하시기 바랍니다.

![라크리모사](./docs/Lacrimosa.png)라크리모사이 대신 낚시를 진행해 드립니다.

[최신 버전 다운로드](https://github.com/HeadmasterTan/NTEFishingTool/releases/tag/v1.1.4) | [이전 버전 목록](https://github.com/HeadmasterTan/NTEFishingTool/releases)

## 📘 사용 설명

* `zip` 파일의 압축을 해제한 후, `NTEFishingTool.exe`를 **관리자 권한으로 실행**해 주세요.

* 본 툴은 '자동 낚시'와 '낚시 중지' 두 개의 버튼만 있으며, `F11` 단축키로 간편하게 시작/중지할 수 있습니다.

* 사용 전 주의사항
	1. 현재 `16:9`, `16:10`, `24:10`, `35:10` 총 4가지 화면 비율을 지원합니다. 설정이 일치하는지 확인해 주세요.
		- 예: `1920 ÷ 1080 = 1.777`은 `16 ÷ 9 = 1.777`에 해당하므로 직접 체크해 보시기 바랍니다.
	2. 게임 화면은 '창 모드' 또는 '테두리 없는 전체 화면(전체 창 모드)'으로 설정을 권장하며, 해상도가 너무 높지 않은 것을 추천합니다 (게임 설정을 4K 해상도로 할 경우 툴 성능이 저하될 수 있습니다).
	3. 게임 화면이 모니터 구석에 가려지지 않고 데스크톱에 온전히 노출되도록 해주세요.
	4. 반드시 아래와 같은 낚시 화면에 진입한 후에 본 툴을 실행해 주세요.
	![낚시 화면](./docs/FishingScene.png)

* '자동 낚시'가 시작된 후에는 '낚시 중지'를 누르기 전까지 컴퓨터 조작을 삼가해 주세요. 툴 작동에 방해가 될 수 있습니다.

## ✨ 주요 기능

1. 자동 낚시 기능
2. 낚시 미끼 자동 구매 (※ 단, '만능 미끼'만 구매합니다)
3. 낚은 물고기 자동 판매 (인벤토리가 가득 차거나 미끼가 다 떨어졌을 때 실행)
4. 월간 패스 화면 자동 건너뛰기
5. 로그인 튕김 현상 발생 시 타이틀 화면에서 게임 자동 재진입
6. 다국어를 지원합니다.
7. 대부분의 화면 비율 및 해상도 호환

## ❔ Q&A

### Q: 커서가 녹색 게이지를 따라가지 못합니다.

- 게임 화질이나 해상도를 낮춰보세요.
- 색상 강화나 화면 필터 등의 기능을 사용 중이라면 비활성화(Off)하는 것을 권장합니다.
- 현재 진행 중인 낚시터의 배경이 너무 복잡할 수 있습니다. 다른 낚시터로 이동해 시도해 보세요.
- AMD 그래픽카드를 사용하는 경우, 프레임 생성(Frame Generation) 기능을 꺼보세요.
- 위의 방법으로도 해결되지 않는다면 현재로서는 도움을 드리기 어렵습니다.
