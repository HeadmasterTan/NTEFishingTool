
# 🎣 異環釣魚工具

本工具基於`OpenCV`，所以不能掛後台，望周知。

![安魂曲](./docs/Lacrimosa.png)讓安魂曲幫你釣。

[曆史版本](https://github.com/HeadmasterTan/NTEFishingTool/releases)

## 📘 使用說明

* 本工具只有 `自動釣魚` 和 `停止釣魚` 兩個按鈕，並設置有按鍵`F11`可直接啟動/停止。

* 使用前
	1. 目前兼容 `16:9` `16:10` `24:10` `35:10` 四種類型的解析度，請注意是否一致。
		- 例如：`1920 ÷ 1080 = 1.777`就是`16 ÷ 9 = 1.777`，請自行檢查。
	2. 建議設置為視窗或無邊框全螢幕，建議解析度不要太高（遊戲設置4K解析度時工具性能會降低）。
	3. 請保持遊戲介面完整暴露在桌面，不要被螢幕邊角遮擋。
	4. 請確保在如下介面後，再啟用本工具。
	![釣魚界面](./docs/FishingScene.png)

* `自動釣魚`後，除非點擊 `停止釣魚`，請勿繼續操作電腦，否則影響工具工作。

## ✨ 涵蓋功能

1. 自動釣魚
2. 自動購買魚餌（但是只會購買萬能魚餌）
3. 自動出售魚獲（滿倉和魚餌用完時觸發）
4. 自動跳過月卡
5. 自動從踢出登錄頁重新進入遊戲
6. 支持多語言
7. 支持大部分的螢幕比例解析度

## ❔ Q&A

### 問：光標跟不上綠條？

- 可以適當降低遊戲畫質或解析度。
- 可能是設置過色彩增強、濾鏡等功能，建議關閉。
- 可能是處在的釣魚區域背景過於複雜，可以嘗試換個釣魚點。
- 如果是AMD顯卡，可以嘗試關閉幀生成。
- 如果上述均無法解決，暫時我也無法幫到你。
