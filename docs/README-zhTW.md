
# 🎣 異環釣魚工具

本工具基於`OpenCV`，所以不能掛後台，望周知。

![安魂曲](./Lacrimosa.png)讓安魂曲幫你釣。

[點擊下載最新版](https://github.com/HeadmasterTan/NTEFishingTool/releases/tag/v1.0.5)

## 📘 使用說明

* 本工具只有 `自動釣魚` 和 `停止釣魚` 兩個按鈕

* 使用前
	1. 目前兼容 `16:9` `16:10` `24:10` `35:10` 四種類型的分辨率，請注意是否一致。
		- 例如：`1920 ÷ 1080 = 1.777`就是`16 ÷ 9 = 1.777`，請自行檢查。
	2. 建議分辨率設置為`16:9`，建議設置為窗口或無邊框全屏。
	3. 請保持遊戲界面完整暴露在桌面，不要被屏幕邊角遮擋。
	4. 請確保在如下界面後，再啟用本工具。
	![釣魚界面](./FishingScene.png)

* `自動釣魚`後，除非點擊 `停止釣魚`，請勿繼續操作電腦，否則影響工具工作。

## ✨ 涵蓋功能

1. 自動釣魚
2. 自動購買魚餌（但是只會購買萬能魚餌）
3. 自動出售魚獲（滿倉和魚餌用完時觸發）
4. 自動跳過月卡
5. 自動從踢出登錄頁重新進入遊戲
6. 支持多語言
