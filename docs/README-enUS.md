
# 🎣 NTEFishingTool

This tool is based on `OpenCV`, so it cannot run in the background. Please be aware.

![Lacrimosa](./Lacrimosa.png)Let Lacrimosa fish for you.

[Click to download the latest version](https://github.com/HeadmasterTan/NTEFishingTool/releases/tag/v1.0.5)

## 📘 Instructions

* This tool only has two buttons: `Auto Fishing` and  `Stop Fishing`.

* Before use:
	1. Currently compatible with four resolution ratios: `16:9`, `16:10`, `24:10`, and `35:10`. Please check if yours matches.
		- For example: `1920 ÷ 1080 = 1.777`, which is `16 ÷ 9 = 1.777`. Please check this yourself.
	2. It is recommended to set the resolution to `16:9`, and set the display mode to Windowed or Borderless Fullscreen.
	3. Please keep the game interface fully exposed on the desktop and not blocked by the screen edges or corners.
	4. Please ensure you are on the following screen before enabling this tool.
	![Fishing Scene](./FishingScene.png)

* After enabling `Auto Fishing`, do not operate your computer unless you click `Stop Fishing`, otherwise it will interfere with the tool.

## ✨ Features

1. Auto fishing
2. Auto buy bait (only buys Universal Bait)
3. Auto sell fish (triggered when inventory is full or bait runs out)
4. Auto skip monthly card pop-ups
5. Auto re-login and re-enter the game if kicked out
6. Multi-language support
