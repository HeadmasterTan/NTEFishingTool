
# 🎣 NTE Fishing Tool

This tool is based on `OpenCV`, so it cannot run in the background. Please be aware.

## 📘 User Guide

* After extracting the zip file, simply run `NTEFishingTool.exe` as an administrator.

* This tool features only two buttons: `Auto Fish` and `Stop Fishing`. You can also press `F11` to directly start or stop the tool.

* Before Use:
	1. It currently supports four aspect ratios: `16:9`, `16:10`, `24:10`, and `35:10`. Please check if your screen matches.
		- For example: `1920 ÷ 1080 = 1.777`, which equals `16 ÷ 9 = 1.777`. Please calculate yours to verify.
	2. We recommend using Windowed or Borderless Fullscreen mode. Avoid excessively high resolutions (running the game at 4K will reduce tool performance).
	3. Keep the game interface fully visible on your desktop. Do not let any parts get cut off by screen edges.
	4. Ensure you are on the specific screen shown below before enabling the tool.
	![Fishing Scene](./docs/FishingScene.png)

* Once `Auto Fish` is active, do not use your computer unless you click `Stop Fishing`. External inputs will disrupt the tool.

## ✨ Features

1. Auto Fishing
2. Auto Bait Purchase (Note: Only purchases Universal Bait)
3. Auto Fish Salvage/Sale (Triggered when inventory is full or bait runs out)
4. Auto Skip Monthly Card pop-ups
5. Auto Re-login (Reconnects if kicked to the login page)
6. Multi-language support
7. Supports most screen aspect ratios and resolutions

## ❔ Q&A

### Q: The cursor cannot keep up with the green bar?

- You can lower the game's graphics quality or resolution accordingly.
- Color enhancement or filter features might have been enabled; it is recommended to turn them off.
- The background of your current fishing area might be too complex. Try switching to a different fishing spot.
- If you use an AMD graphics card, try disabling Frame Generation.
- If none of the above solutions work, there is unfortunately no other fix available at this moment.
