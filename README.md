## 📘 使用说明

* 本工具只有 `自动钓鱼` 和 `停止钓鱼` 两个按钮

* 使用前
	1. 目前兼容 `16:9` `16:10` `24:10` `35:10` 四种类型的分辨率，请注意是否一致。
		- 例如：`1920 ÷ 1080 = 1.777`就是`16 ÷ 9 = 1.777`，请自行检查。
	2. 建议分辨率设置为`16:9`，建议设置为窗口或无边框全屏。
	3. 请保持游戏界面完整暴露在桌面，不要被屏幕边角遮挡。
	4. 请确保在如下界面后，再启用本工具。
	![钓鱼界面](./docs/FishingScene.png)

* `自动钓鱼`后，除非点击 `停止钓鱼`，请勿继续操作电脑，否则影响工具工作。

## ✨ 涵盖功能

1. 自动钓鱼
2. 自动购买鱼饵（但是只会购买万能鱼饵）
3. 自动出售鱼获（满仓和鱼饵用完时触发）
4. 自动跳过月卡
5. 自动从踢出登录页重新进入游戏
6. 支持港澳台、以及国际服
