
## 异环钓鱼工具

本工具基于`OpenCV`，所以不能挂后台，望周知。

### 使用说明

* 本工具只有 `自动钓鱼` 和 `停止钓鱼` 两个按钮

* 使用前
	1. 请将游戏界面语言设置成【简体中文】。
	2. 本工具仅支持`2560*1440窗口`、`1920*1080窗口`以及`1280*720窗口`，但是建议分辨率设置越低越好。
	3. 请保持游戏界面完整暴露在桌面，不要被屏幕边角阻挡。
	4. 请确保在如下界面后，再启用本工具。
	![钓鱼界面](./docs/FishingScene.png)


* `自动钓鱼`后，除非点击 `停止钓鱼`，请勿继续操作电脑，否则影响工具工作。

### 涵盖功能

1. 自动钓鱼
2. 自动购买鱼饵（但是只会购买万能鱼饵）
3. 自动出售鱼获
