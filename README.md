## 📘 使用说明

* 将`zip`解压后，`以管理员身份`运行`NTEFishingTool.exe`即可。

* 本工具只有 `自动钓鱼` 和 `停止钓鱼` 两个按钮，并设置有按键`F11`可直接启动/停止。

* 使用前
	1. 目前兼容 `16:9` `16:10` `24:10` `35:10` 四种类型的分辨率，请注意是否一致。
		- 例如：`1920 ÷ 1080 = 1.777`就是`16 ÷ 9 = 1.777`，请自行检查。
	2. 建议设置为窗口或无边框全屏，建议分辨率不要太高（游戏设置4K分辨率时工具性能会降低）。
	3. 请保持游戏界面完整暴露在桌面，不要被屏幕边角遮挡。
	4. 请确保在如下界面后，再启用本工具。
	![钓鱼界面](./docs/FishingScene.png)

* `自动钓鱼`后，除非点击 `停止钓鱼`，请勿继续操作电脑，否则影响工具工作。

## ✨ 涵盖功能

1. 自动钓鱼
2. 自动购买鱼饵（但是只会购买万能鱼饵）
3. 自动出售鱼获（满仓和鱼饵用完时触发）
4. 自动跳过月卡
5. 自动从踢出登录页重新进入游戏
6. 支持港澳台、以及国际服
7. 支持大部分的屏幕比例分辨率

## ❔ Q&A

### 问：光标跟不上绿条？

- 可以适当降低游戏画质或分辨率。
- 可能是设置过色彩增强、滤镜等功能，建议关闭。
- 可能是处在的钓鱼区域背景过于复杂，可以尝试换个钓鱼点。
- 如果是AMD显卡，可以尝试关闭帧生成。
- 如果上述均无法解决，暂时我也无法帮到你。
